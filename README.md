# TypeScript

TypeScript is a strongly typed programming language that builds on JavaScript, adding optional static type checking, interfaces, generics, and other features. Developed and maintained by Microsoft, TypeScript compiles to plain JavaScript and is widely used for large-scale web applications, Node.js services, and developer tooling.

**URL:** [https://www.typescriptlang.org](https://www.typescriptlang.org)
